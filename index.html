I'm Jhon Elopre — a Full-Stack Web & Mobile Developer. I build and deploy responsive websites and single-page applications with HTML, CSS, JavaScript, PHP, Bootstrap, and React.js, and cross-platform mobile apps with Flutter.

As a results-driven system builder, I've designed platforms like Alumni Tracking and Barangay Management to improve workflow efficiency, record management, and print-ready document generation. I'm also an AI enthusiast — I built an LSTM-based NLP Career Recommendation System using Python, OCR (Tesseract), and machine learning tools for data-driven decision support.

I graduated with a Bachelor of Science in Computer Science from Pamantasan ng Lungsod ng Muntinlupa (2021–2025). I'm currently working as a Developer at a private school in Taguig, and I've freelanced as a Web & Mobile Developer since January 2023 (including Intern Programmer work on Alumni Tracking and OJT Portal, Aug–Nov 2025).

  • Systems for alumni, barangay, and institutional workflows

  • REST APIs, MySQL, Firebase, GitHub & CI/CD
